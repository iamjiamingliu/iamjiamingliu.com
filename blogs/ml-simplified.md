## 前言

我刚开始编程的时候（2020年左右，16岁）就跟着网上GeeksForGeeks教程试着学习人工智能，
结果各种代码库、数学理论、数据处理，把我搞得云里雾里，于是我一败涂地，没学下来。

几年过去了，我又多次尝试再学人工智能，学它的本质，学它的数学理论，学它的工程，并思考他对社会和个人的影响。
直到最近，我才入门了。

现在2026了，网上各种贩卖AI焦虑的标题党一个接一个，
但是AI产品，国内的豆包，外国的ChatGPT，也落实到了亿万人上。
从外行角度看，AI既是一个过度宣传贩卖的风口，但也确实是一个很神奇，并且落实到生活中的有用帮手。

从内行来看，AI也是一个很神奇的技术，但剥开其华丽的外衣，其实就是一坨代码罢了。
但是加在一起，就能到达很神奇的效果。

对于大学生，AI则是老师张口闭口谈的风口——但是他们讲AI，就会给你先把线性代数、概率学过一遍，
最后真正学到的，不多。而且则是偏理论。会有几个上手的例子，但是其本质逻辑，老师很少回去讲懂。
于是好多课都被一个个公式和一张张图片破坏掉了。

我想借此文章，分享一下，我对AI作为初学者的理解。
我对传统后端工程了解很深，但是对于AI，只能做到入门。
但是我很自信我描述能力强，所以，但愿此文章能帮你剥开云雾，看看本质，有些不一样的思考。

## 权重总和

军师A说：

1. 她同意加你微信了: +10 分
2. 她朋友圈没有男朋友: +0 分。要不然-100分
3. 15分钟就回消息：我们加个平均（回复时间 - 30）分。15，那就是 +15分。回太晚了，减分。回快了加分
4. 你丑，-2 分
5. 很多表情，+ 10 分
6. 用了💕这种稀有emoji？+ 40分

军师A说，你算算你多少分。大于20分等于有戏，小于20分的话，你就拉倒吧。

## 判断是非

军师B说：

- 如果她不同意加你微信，直接歇菜，她不感兴趣
- 如果加了：
  - 如果朋友圈有男朋友，直接歇菜
  - 如果没有男朋友：
    - 回复消息等待超过6小时，直接歇菜
    - 回复消息等待小于6小时的话：

      - 你还行：

军师B说，你按照我的判断思路看看，看看你有戏没戏。

## 判断题，数据，因子，输出

我们可以看到啊，
我们面对的是一个判断题：
她喜欢你吗？

我们的数据是，几轮聊天交手。

从几轮聊天交手，我们提炼几个会影响到判断结果的因子：
她有没有接受你的好友请求、她有没有男朋友、她回复消息多久、等。

我们的输出是一个是与否：她喜欢你吗？

（例子里，她居然喜欢你！没错，你一个呆头呆脑书呆子，她一个天仙下凡的啦啦队，居然能走到一起。于是你们度过了一段很跌宕起伏的青春里最好的一年，然后淡然结束。
于是现在就留下你写着博客回忆着过去。当然，这只是个例子——吗？言归正传。）

## 线性模型

我谈人工智能，先谈个儿女情长干嘛？

因为这个例子很好地诠释了人工智能的一个底层本质：
人工智能，就是借助电脑和数学，做判断题。
那人工智能怎么做判断呢？
你给它输入几个因子，它计算一下，产出一个值。如果这个值足够大，就是Yes。反之就是No。
仅此而已。

回到军师A。
军师A的判断法是，
你把 她有没有接受你的好友请求、她有没有男朋友、她回复消息多久、等因子，
每个乘上一个分（接受你的好友请求：+10，她有没有男朋友：-100，回复消息延迟：-1），
加起来，
然后大于20分等于有戏，小于20分的话，你就拉倒吧。

这就是人工智能里最经典，最简单，但目前依旧广泛运用的模型：线性模型。
因为，你把各个因子加起来，加权重，最后看看总和，这个过程，
数学上就是线性代数里的总和，所以叫做线性模型。

代码层面上，这个判断大概就是：

```python
# 各个因子
added_your_wechat = 1           # 加了微信
has_boyfriend = 0               # 没有男友
avg_message_reply_delay = 25    # 平均回消息等多久

# 权重
added_your_wechat_weight = 10          # 加了微信，是好事
has_boyfriend_weight = -100            # 有男友了，就完蛋
avg_message_reply_delay_weight = -1    # 越快越好，慢了扣分

# 判断。注意，* 在代码里是乘的意思
is_she_into_you = added_your_wechat * added_your_wechat_weight + has_boyfriend * has_boyfriend_weight + avg_message_reply_delay * avg_message_reply_delay_weight

if is_she_into_you > 20:
    print('恭喜')
else:
    print('哥布林，你还是回山洞去吧')
```

真正代码实现线性模型的时候，有几个问题：

1. 权重是不会手写的，而是机器自己学习得到的最权重
2. 机器怎么学习？你给它好多个例子。现在只有你一个人的例子。你假设有成百上千个前人表白成功失败的例子，线性模型就能很好地学习到最好的权重
3. 这个学习的过程，就是：模型训练！
4. 问：那怎么模型训练呢？具体学习，学了个啥？答：对于线性代数，有一个最优解的算法，或者现如今更常见的是gradient descent，俗称：你先随机生成一个权重，用它做预测，看看错了多少。你比较一下哪里错了，然后通过哪里错了，你可以数学角度上知道你各个权重要加一点还是减一点。反复好几次，你模型的学习到的权重就是最优解了。具体数学和代码不展开展示了。

理解人工智能模型，最重要在于要理解：

1. 它是干嘛用的？做判断
2. 什么判断？因任务而异。在以上例子里，我们要判断她是否喜欢你
3. 什么是数据，什么是因子？
4. 我们怎么判断？各种模型有不同的判断方法。线性模型里，判断方法就是每个因子乘以权重，然后加起来
5. 什么是训练模型？什么是机器学习？就是找权重的过程。我们不能手工加权重，而是自动的
6. 怎么训练模型？线性模型里，可以用gradient descent来一坨随机的权重慢慢通过一次次错误的捕捉而慢慢变更我们的权重，最后达到最优解
